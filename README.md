# Docuro AI — Website

AI Accounting Automation Platform for Indian Businesses & Chartered Accountants.

Marketing website + legal pages for [docuroai.in](https://docuroai.in).

## Stack

- Static HTML / CSS / vanilla JS
- Premium SaaS design system (glassmorphism, gradients, smooth animations)
- Hosted on Cloudflare Pages

## Pages

- `/` — Homepage
- `/about/` — About Us
- `/pricing/` — Pricing
- `/contact/` — Contact
- `/faq/` — FAQ
- `/privacy-policy/` — Privacy Policy
- `/terms-and-conditions/` — Terms & Conditions
- `/refund-policy/` — Refund Policy
- `/cancellation-policy/` — Cancellation Policy
- `/404.html` — Premium 404

## Local development

```bash
# Any static server works. Example:
npx serve .
# or
python -m http.server 3000
```

## Deployment

Auto-deployed to Cloudflare Pages on every push to `main`.
